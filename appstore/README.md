# App Store screenshots

iPhone 6.5" display size — **1242 × 2688** — the size App Store Connect
asks for. Uploaded in filename order; the first two are what show in
search results.

Produced from the simulator captures in `docs/screenshots/`
(iPhone 17 Pro Max, 1320 × 2868) by scaling to cover and centre-cropping
11px of height, so nothing is distorted or letterboxed.
